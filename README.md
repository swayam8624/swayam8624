## About Me

I am **Swayam Singal**, a builder working across C++ engine foundations, AI/security systems, Blender environments, games, research, and long-form writing.

I like projects that sit at the boundary between systems and craft: math libraries for 3D engines, LLM security gateways, ML infrastructure, GPU benchmarks, game/runtime experiments, and visual worlds made in Blender.

- **Current Focus:** Kairo, a custom 3D engine roadmap built from the foundation upward.
- **Availability:** Open to freelance, available June 2026.
- **Creative Work:** Blender renders, game systems, visual archives, and philosophical writing.
- **Research:** Cognitive AI, LLM compression, MLOps, and artifact storage.

## Featured Work

### Kairo / KairoMath
[![GitHub](https://img.shields.io/badge/GitHub-KairoMath-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/KairoMath)

A C++23 3D engine foundation and math library roadmap covering math, geometry, spatial structures, physics, CPU rendering, Vulkan rendering, ECS, assets, serialization, and editor tooling.

### Sentinel + CipherMesh
[![GitHub](https://img.shields.io/badge/GitHub-Sentinel-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/Sentinel)

Go-based LLM security gateway with PII redaction, prompt sanitization, policy enforcement, provider adapters, and audit trails.

### SME Finance Hub
[![GitHub](https://img.shields.io/badge/GitHub-SME_ERP_SWAYAM-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/SME_ERP_SWAYAM)

Production-focused finance platform for Indian SMEs with GST, bank reconciliation, reports, offline-first sync, Supabase security, and local AI workflows.

### BentoML Recreation
[![GitHub](https://img.shields.io/badge/GitHub-bentomlReCreation-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/bentomlReCreation)

GPU inference benchmark comparing BentoML-style serving against LMDeploy/TurboMind with throughput, MFU, latency, and power telemetry.

### ReliQuary
[![GitHub](https://img.shields.io/badge/GitHub-ReliQuary-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/ReliQuary)

Rust-based content-addressed artifact store for ML experiment lineage, metadata tagging, and reproducible model retrieval.

### Memory Retrieval Cue
[![GitHub](https://img.shields.io/badge/GitHub-Memory_Retrieval_Cue-black?style=for-the-badge&logo=github)](https://github.com/swayam8624/Memory-Retrieval-Cue)
[![DOI](https://img.shields.io/badge/DOI-10.7759/s44389--025--03357--2-blue?style=for-the-badge)](https://doi.org/10.7759/s44389-025-03357-2)

EEG cognitive AI research using a hybrid CNN + LSTM pipeline to improve memory recall prediction.

## Games & Graphics

- **NES Emulator** - cycle-accurate emulator work covering 6502 CPU, PPU, memory mapper support, and controller input.
- **Vulkan Engine MINI** - minimal Vulkan renderer with instance, device, swapchain, render pass, pipeline, and vertex buffers.
- **Metal Engine Beginner** - macOS Metal renderer using C++, Objective-C, MSL shaders, command buffers, and render encoders.
- **Productivity App** - Rust-backed desktop pet and active-window tracker.
- **JavaMadDawg** - pure Java arcade game built with AWT/Swing, custom loop, sprites, collision, and input.
